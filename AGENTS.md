# BinderClip Agent Guide

- Keep changes separated by concern: protocol/features, networking, storage, and tooling.
- Update this file when an essential project convention, build command, or architecture detail changes. Keep it concise.
- macOS debug install: `./macos/debug-install.sh`.
- macOS production package: `./macos/package-release.sh`; it bundles Sparkle 2 and creates an ad-hoc signed universal ZIP, DMG, and signed appcast.xml using BWS secrets.
- macOS tests: `swift test --package-path macos/BinderClipMac`.
- Android tests: `./android/gradlew -p android test`.
- Android local Gradle verification uses Java 21 (`JAVA_HOME=$HOME/.local/share/mise/installs/java/21.0.2`); Java 26 fails Android SDK JDK-image transforms.
- Star topology: macOS runs a permanent `NWListener` WebSocket server (`WebSocketServer`) on port `39421`; Android is a resilient client (`WebSocketClient`) with a single exponential backoff (`1s -> 2s -> … -> 16s`). Connection presence is live-only (never persisted). A session is alive only if it is authenticated, its bound local IPv4 still exists, and an application JSON heartbeat (`ping`/`pong` every 2s, 5s budget) has been heard. Mac watches interface IPv4 via `SCDynamicStore` (split-tunnel VPN does not change the default `NWPath`) and evicts only sessions whose bound address disappeared. There is no mesh/chain, no Android hosting, and no Mac-as-client join path.
- Pairing: Mac **Add Device** QR is `binderclip://pair` with a URL-safe Base64 PSK and up to four sorted IPv4 endpoints (LAN, then Tailscale `100.x`, then other unicast). Never advertise loopback. Unpairing a phone does not tombstone it; the same device can scan the same QR again. **Reset pairing key** rotates the PSK and requires every phone to rescan.
- Multi-endpoint racing (Happy Eyeballs): Android races all QR endpoints in parallel so LAN, Tailscale, WireGuard, and Cloudflare Zero Trust work without a relay.
- Text and browser URLs are UTF-8 JSON frames; PNG/JPEG/WebP/HEIC images (up to 30 MiB) are atomic binary WebSocket messages (`[4-byte metadata length] + [JSON header] + [Raw image bytes]`). The wire is cleartext `ws://` on a trusted LAN/VPN; the PSK gates who may connect.
- Clipboard classification is fail-closed: file URLs take precedence over TIFF/icons/text, but only supported image files are sent. All other files are ignored and must never be coerced into a filename string.
- Single-variable SHA-256 hash checking prevents clipboard echo loops. Unpairing clears local paired state while preserving the stable local identity.
- Android’s share target accepts supported images and text/URLs. It offers an interactive device picker to choose the target device (or all devices); when sharing a web URL (`http://`/`https://`), BinderClip sends an `openUrl` command that automatically launches the default browser on the target device. Incoming `openUrl` on Android cannot start a browser from the background service; it posts a **Browser Links** notification that opens the URL on tap. Automatic clipboard sync uses the app-owned root bridge for text/images only after KernelSU/Magisk grants `su`; it then grants BinderClip `READ_CLIPBOARD_IN_BACKGROUND` and revokes it when the toggle turns off. Otherwise it uses the user-enabled `ClipboardAccessibilityService` for text only. That service must remain clipboard-only: no window retrieval, gestures, or accessibility-event interpretation.
- Android background help may request the standard battery-optimization allowlist and open App Info for OEM Auto Start controls. Manufacturer-specific auto-start intents (Xiaomi/MIUI, OPPO/ColorOS, Vivo, Huawei/Honor, OnePlus/Realme) are attempted with `resolveActivity` checks and `try-catch` fallback to `ACTION_APPLICATION_DETAILS_SETTINGS`. Do not hardcode private intents without fallback.
- On macOS, list blocking Local Network and (macOS 15.4+) denied Clipboard Access at the top of the status menu. Launch at Login is an opt-in under **More**, not a permission nag. Local Network privacy is tracked reliably in distribution only with an Apple-issued signing identity; do not claim a denied/allowed state before Network.framework reports it. The status menu lists phones only (not This Mac); **Reset pairing key**, logs, and updates live under **More**. The status item is template-safe and dims when no session is connected.
- Store CI credentials in BWS first; GitHub Actions should use only the BWS access token to load project secrets at runtime. Do not commit or print secret values.
- Do not revert unrelated worktree changes.
